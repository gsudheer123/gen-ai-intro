# Gen AI Intro - Fall 2024 Training

Welcome to the Generative AI Introduction training repository! This repository contains comprehensive sample code and educational materials for hands-on Gen AI projects and learning.

## 📚 What's Inside

This repository includes Jupyter notebooks covering essential LLM and Generative AI topics:

- **Introduction to Gen AI API** - Getting started with Google AI Studio and Vertex AI
- **Text Summarization** - Automated text summarization techniques
- **Text Extraction** - Structured data extraction from unstructured text
- **Text Classification** - Document and content classification systems
- **Question Answering** - Open and closed domain Q&A systems
- **Ideation** - Creative content generation and brainstorming
- **Chain of Thought & ReAct** - Advanced reasoning and problem-solving
- **Custom Prompting** - Domain-specific prompt engineering
